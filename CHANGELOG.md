# Changelog

## 0.1.0 - 2026-09-16

- First stable community release.
- Registers as **Netflix** in the desktop app launcher with Netflix's website icon.
- Opens Netflix in a dedicated Chromium profile and normal browser window.
- Preserves login data across reinstall, package upgrade and removal.
- Provides user-local installation and an Arch package recipe with safe migration from local installs.
- Keeps Chromium sandboxing and GPU defaults enabled.
- Uses the normal-window Chromium path verified for protected playback on the target Omarchy system.
